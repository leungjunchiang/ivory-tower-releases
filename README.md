# 象牙塔 · 公开发行

这是象牙塔的公开下载、更新说明与校验清单仓库。开发源码单独管理。

**0.4.0 正在完成发布验收，尚未公开发布。** 验收通过后，安装包会出现在 [Releases](https://github.com/leungjunchiang/ivory-tower-releases/releases)。这里不要求登录 GitHub 下载已公开的附件。

支持 Windows x64、Mac Apple Silicon 与 Mac Intel。Windows 使用 EXE 安装器；Mac 使用 DMG，将“象牙塔.app”拖入 Applications。请选择匹配的架构。

0.4.0 新增免密码启动、今日/资料库/订阅/设置、公众号应用内扫码授权、重点/普通/静默优先级、浮动批注和笔记侧栏、Markdown/Obsidian 导出、缓存正文与笔记搜索，以及经过大小和 SHA-256 校验的完整包更新。

Windows 安装器未签名；Mac ad-hoc 签名，未使用 Apple Developer 分发证书或 Apple 公证。首次安装可能出现系统安全提示。发布时提供 `SHA256SUMS.txt`，请从本仓库取得安装包与校验清单。

软件不提供微博、小红书的评论、点赞和发帖操作，只读取匿名可见公开内容；平台登录/验证限制可能使内容不完整。公众号历史依授权通道可见范围采集。
